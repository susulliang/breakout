# Breakout v0.3 - Isometric 3D Prototype

v0.3 is an incremental 3D rendering prototype, not the completed 3D port.

## Included

- Deterministic gameplay/map state with canonical ground-cell coordinates.
- Orthographic 3D camera, ground-plane cursor picking, and `--renderer=2d|3d`
  plus F8 backend switching.
- Cached 16x16 floor and wall meshes with depth testing.
- Existing gameplay systems and 2D renderer retained as the default fallback.
- Headless math, gameplay-parity, and map-mesh tests.
- Model authoring/export contract prepared for the later pose/socket milestone.

## Not Yet Included

- Physical 3D projectile sweeps and shared world-space hit volumes.
- Final character, weapon, and prop models; current 3D actor geometry is
  diagnostic.
- World-space debris, lighting, visual parity/performance acceptance, or
  making 3D the default.

## Local Verification

Configure with the available repository-local toolchain, build, and run:

```powershell
cmake -S . -B build/port3d -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=OFF -DBUILD_TESTING=ON
cmake --build build/port3d --parallel
ctest --test-dir build/port3d --output-on-failure
.\build\port3d\bin\Breakout.exe --renderer=3d
```

The port work to date was built on Windows with a local Raylib source override.
Interactive camera, occlusion, resize, and repeated GPU-resource rebuild checks
remain outstanding.
